2. Conéctate a tu servidor de SQL Server.
3. Selecciona “New Query / Nueva consulta”.
4. Abre o pega el archivo .sql incluido.
5. Ejecuta TODO el script con Execute o F5.
6. El script elimina y vuelve a crear la base SuperAhorro_C260104, por lo que debe ejecutarse con una cuenta que tenga permisos para crear bases de datos.
7. Al finalizar verás los resultados de las 10 consultas solicitadas y consultas de validación.
